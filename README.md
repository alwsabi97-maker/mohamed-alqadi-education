# Mohamad Al-Qadi Education App

تطبيق تعليمي عربي مصمم للطلاب مع:
- دخول الطلاب باستخدام كود خاص
- قراءة ملازم PDF محلية
- اختبارات داخل التطبيق
- حفظ النتائج محلياً
- شاشة تعريف المعلم
- شاشة إدارة المعلم (قيد التوسعة لاحقاً)

## التثبيت

1. تثبيت Flutter SDK.
2. افتح المشروع.
3. شغّل:
   flutter pub get
   flutter run

## ملاحظة

النسخة الحالية هي هيكل أولي جاهز للتوسعة. يتم ترك إضافة ملفات PDF والأكواد الفعلية والواجهة الإدارية المتقدمة لاحقاً.
